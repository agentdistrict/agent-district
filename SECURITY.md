# Security policy

## Scope

This policy covers the current [Agent District web application](https://agentdistrict.world), including wallet sign-in, signature prompts, and Workspace. It also covers security issues in the files published in this repository.

## Report a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/agentdistrict/agent-district/security/advisories/new) to contact the maintainers. Keep vulnerability details in the private report.

Include the affected page or feature, the behavior you observed, and its potential impact. Add your browser, wallet app, and approximate time of the event if they help explain what happened. Attach redacted screenshots or logs when useful.

Keep recovery phrases, private keys, wallet signatures, passwords, session tokens, and private Workspace contents out of the report and any attachments.
