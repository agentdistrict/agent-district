# Contributing to Agent District

This repository contains the public product documentation for [Agent District](https://agentdistrict.world). Contributions can include corrections to service descriptions, clearer instructions, and fixes for broken links.

## Suggest a change

Open a [GitHub issue](https://github.com/agentdistrict/agent-district/issues/new) with the affected page or section, what you found, and the change you suggest. For a straightforward correction, you can also open a pull request against `main`.

## Open a pull request

- Keep the change focused and explain why it helps readers.
- Check product claims against the live site and use the labels readers will see there.
- Review the rendered Markdown and follow any links you changed. The [Documentation links workflow](.github/workflows/link-check.yml) checks relative paths, Markdown anchors, and public Agent District URLs.

## Security reports and rights

Follow [SECURITY.md](SECURITY.md) to report a vulnerability privately. Keep personal data and account secrets out of public issues and pull requests.
